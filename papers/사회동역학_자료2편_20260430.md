## 1. 인프라 — WSL2 + Claude Code + GitHub + Netlify

**파이프라인 구성 (2026-04-29 구축, 04-30 검증):**

```
Windows 11
  └─ WSL2 (Ubuntu)
       └─ Claude Code (Opus 4.7, 1M context)
            └─ /home/badaegopa/-everbluesea  (작업 디렉토리)
                 └─ git push → GitHub: badaegopa/-everbluesea
                                  └─ Netlify auto-deploy → everbluesea.org
                                  └─ Tistory 수동 발행 (HTML 직접 붙여넣기)
```

**검증된 워크플로우:**
1. Windows Downloads에서 받은 파일을 WSL 경유로 repo에 즉시 통합
2. Claude Code가 디자인 시스템(v2.2 Pastel) 일관성 유지하며 HTML 생성
3. SVG 다이어그램 포함 단일 파일 산출 — Tistory 호환 (var/import/script 없음)
4. git commit → push → 자동 배포 (작업 종결까지 1턴)

**도메인:** `everbluesea.org` (CNAME 등록 완료)

### 핵심 명제

> **같은 전쟁(1991~95 유고슬라비아 해체)이 30년 후 세 개의 다른 좌표를 만들어냈다.**
> 분기를 결정한 외부 변수는 EU 통합 단계, 내부 변수는 Σ(지도자-민중 단절). 두 변수가 같은 방향이면 안정 끌개(HRV), 충돌하면 진동(SRB), 모두 봉쇄되면 혼돈(BIH).

### 5개 다이어그램 구성

1. **4-orbit 위상 궤도** — 안정/주의/경계/위험 동심원 + 1990 출발점에서 분기
2. **Σ × TBI 사분면** — Healing / Bifurcation / Stable / Drift 4분면, 3국 좌표
3. **GPI 시계열 1990–2025** — Dayton·Kosovo·HRV→EU 마커 포함
4. **로지스틱 분기도** — 안정 → 2주기 → 혼돈 영역, 3국 위치 매핑
5. **12축 Λ¹² 레이더** — 3국 폴리곤 중첩 (HRV 그린, SRB 골드, BIH 적색)
